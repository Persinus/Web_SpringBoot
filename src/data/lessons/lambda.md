# Lambda Expression

## Mục tiêu bài học
Viết behavior ngắn gọn và truyền behavior như một giá trị.

## Khái niệm
Lambda đại diện cho một hàm không tên và dùng cùng functional interface.

## Ví dụ code Java
```java
List<String> names = List.of("An", "Binh", "Chi");
names.forEach(name -> System.out.println(name));
```

## Bài tập thực hành
Dùng lambda để lọc danh sách theo điều kiện.
