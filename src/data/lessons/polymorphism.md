# Polymorphism

## Mục tiêu bài học
Dùng cùng một kiểu tham chiếu cho nhiều implementation.

## Khái niệm
Polymorphism cho phép method được dispatch theo object thực tế lúc runtime.

## Ví dụ code Java
```java
Animal animal = new Dog();
animal.speak();
```

## Bài tập thực hành
Tạo danh sách Animal và gọi speak trên từng phần tử.
