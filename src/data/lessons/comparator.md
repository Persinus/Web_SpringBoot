# Comparator

## Mục tiêu bài học
Tạo nhiều cách sắp xếp bên ngoài class dữ liệu.

## Khái niệm
Comparator phù hợp khi cần nhiều tiêu chí sort hoặc không sửa được class gốc.

## Ví dụ code Java
```java
students.sort(Comparator.comparing(Student::getName));
```

## Bài tập thực hành
Sắp xếp danh sách theo điểm giảm dần.
