# for / while / do-while

## Mục tiêu bài học
Lặp lại một đoạn code theo số lần hoặc điều kiện.

## Khái niệm
Dùng `for` khi biết số lần lặp, `while` khi kiểm tra điều kiện trước và `do-while` khi cần chạy ít nhất một lần.

## Ví dụ code Java
```java
for (int index = 0; index < 3; index++) {
  System.out.println(index);
}
```

## Bài tập thực hành
In các số từ 1 đến 10 và tính tổng của chúng.
