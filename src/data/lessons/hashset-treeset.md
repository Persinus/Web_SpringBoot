# HashSet và TreeSet

## Mục tiêu bài học
Lưu tập phần tử duy nhất và phân biệt set không thứ tự với set có sắp xếp.

## Khái niệm
HashSet tối ưu tra cứu, TreeSet duy trì thứ tự theo comparator tự nhiên.

## Ví dụ code Java
```java
Set<Integer> values = new HashSet<>();
values.add(3);
values.add(3);
```

## Bài tập thực hành
Loại bỏ phần tử trùng và sắp xếp kết quả.
