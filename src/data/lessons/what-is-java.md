# Java là gì — JVM, JDK, JRE

## Mục tiêu bài học
Hiểu Java là gì và phân biệt vai trò của JVM, JDK và JRE.

## Khái niệm
Java biên dịch mã nguồn thành bytecode. JVM thực thi bytecode trên từng hệ điều hành, tạo nên khả năng viết một lần và chạy ở nhiều nơi.

## Ví dụ code Java
```java
public class HelloJava {
  public static void main(String[] args) {
    System.out.println("Hello, Java");
  }
}
```

## Tóm tắt
JDK dùng để phát triển, JRE cung cấp môi trường chạy và JVM thực thi bytecode Java.
