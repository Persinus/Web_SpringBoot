# Interface

## Mục tiêu bài học
Định nghĩa contract mà nhiều class có thể triển khai.

## Khái niệm
Interface mô tả khả năng và cho phép một class implement nhiều contract.

## Ví dụ code Java
```java
interface Printable {
  void print();
}
```

## Bài tập thực hành
Tạo interface Flyable và implement cho hai class.
