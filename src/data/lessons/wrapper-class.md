# Wrapper Class

## Mục tiêu bài học
Dùng object wrapper khi API yêu cầu kiểu tham chiếu.

## Khái niệm
Integer, Double và Boolean bao bọc primitive, hỗ trợ null và các method tiện ích.

## Ví dụ code Java
```java
Integer count = 10;
int value = count;
```

## Bài tập thực hành
Chuyển đổi chuỗi sang Integer và xử lý lỗi.
