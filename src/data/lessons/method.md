# Method

## Mục tiêu bài học
Tách logic thành các method có tên và trách nhiệm rõ ràng.

## Khái niệm
Method có thể nhận tham số và trả về kết quả. Việc tách method giúp code dễ đọc và kiểm thử.

## Ví dụ code Java
```java
static int add(int first, int second) {
  return first + second;
}
```

## Bài tập thực hành
Viết method tính diện tích hình chữ nhật.
