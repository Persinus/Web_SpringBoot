# Abstract Class

## Mục tiêu bài học
Tạo class nền tảng không thể khởi tạo trực tiếp.

## Khái niệm
Abstract class có thể chứa state, implementation và abstract method.

## Ví dụ code Java
```java
abstract class Shape {
  abstract double area();
}
```

## Bài tập thực hành
Tạo Shape và các class hình học kế thừa.
