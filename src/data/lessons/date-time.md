# Date / Time API

## Mục tiêu bài học
Làm việc với ngày giờ hiện đại bằng java.time.

## Khái niệm
LocalDate, LocalDateTime và ZonedDateTime immutable, rõ timezone và dễ kiểm thử.

## Ví dụ code Java
```java
LocalDate today = LocalDate.now();
```

## Bài tập thực hành
Tính số ngày giữa hai mốc thời gian.
