# switch

## Mục tiêu bài học
Chọn một nhánh xử lý dựa trên nhiều giá trị cố định.

## Khái niệm
`switch` phù hợp khi cần so sánh cùng một biểu thức với nhiều case.

## Ví dụ code Java
```java
switch (day) {
  case 1 -> System.out.println("Monday");
  default -> System.out.println("Other day");
}
```

## Bài tập thực hành
Tạo menu đơn giản bằng switch expression.
