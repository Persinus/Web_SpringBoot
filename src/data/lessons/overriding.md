# Method Overriding

## Mục tiêu bài học
Thay đổi implementation method kế thừa trong class con.

## Khái niệm
Overriding yêu cầu signature tương thích và thường dùng annotation `@Override`.

## Ví dụ code Java
```java
@Override
void speak() { System.out.println("Woof"); }
```

## Bài tập thực hành
Override method của class cha bằng hành vi riêng.
