# LinkedList

## Mục tiêu bài học
Sử dụng danh sách liên kết khi cần thao tác đầu/cuối thường xuyên.

## Khái niệm
LinkedList lưu node liên kết; truy cập theo index chậm hơn ArrayList.

## Ví dụ code Java
```java
LinkedList<String> queue = new LinkedList<>();
queue.addFirst("first");
```

## Bài tập thực hành
Mô phỏng hàng đợi bằng LinkedList.
