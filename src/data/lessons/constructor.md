# Constructor

## Mục tiêu bài học
Khởi tạo object với state hợp lệ ngay khi được tạo.

## Khái niệm
Constructor có cùng tên class và không có kiểu trả về.

## Ví dụ code Java
```java
Student(String name) {
  this.name = name;
}
```

## Bài tập thực hành
Tạo constructor mặc định và constructor có tham số.
