# Class và Object

## Mục tiêu bài học
Phân biệt class như bản thiết kế và object như một thực thể được tạo ra từ bản thiết kế đó.

## Khái niệm
Class mô tả state và behavior. Object giữ state cụ thể trong bộ nhớ.

## Ví dụ code Java
```java
class Student {
  String name;
  void study() { System.out.println(name + " is studying"); }
}
```

## Bài tập thực hành
Tạo class Student với tên và method giới thiệu.
