# Access Modifier

## Mục tiêu bài học
Kiểm soát khả năng truy cập class, field và method.

## Khái niệm
Các modifier chính gồm public, protected, package-private và private.

## Ví dụ code Java
```java
private String password;
public String getPassword() { return password; }
```

## Bài tập thực hành
Ẩn field và truy cập nó qua getter.
