# Cú pháp Java cơ bản

## Mục tiêu bài học
Nắm cấu trúc class, hàm main, câu lệnh và dấu chấm phẩy trong Java.

## Khái niệm
Java tổ chức chương trình trong class. Mỗi câu lệnh thường kết thúc bằng dấu chấm phẩy và phần thực thi bắt đầu từ hàm `main`.

## Ví dụ code Java
```java
public class Example {
  public static void main(String[] args) {
    System.out.println("Java syntax");
  }
}
```

## Bài tập thực hành
Viết chương trình in ra họ tên và mục tiêu học tập của bạn.
