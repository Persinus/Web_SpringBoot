# Regular Expression

## Mục tiêu bài học
Tìm kiếm và kiểm tra chuỗi theo pattern.

## Khái niệm
Regex phù hợp cho validation có cấu trúc, nhưng nên giữ pattern dễ đọc và dễ kiểm thử.

## Ví dụ code Java
```java
boolean valid = email.matches(".+@.+\\\\..+");
```

## Bài tập thực hành
Kiểm tra email và số điện thoại đơn giản.
