# Generics

## Mục tiêu bài học
Viết collection và method an toàn kiểu, tái sử dụng được.

## Khái niệm
Generics đưa type parameter vào class hoặc method để giảm ép kiểu runtime.

## Ví dụ code Java
```java
List<String> names = new ArrayList<>();
```

## Bài tập thực hành
Viết generic method trả về phần tử đầu tiên.
