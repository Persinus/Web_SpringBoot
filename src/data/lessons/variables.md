# Biến và kiểu dữ liệu

## Mục tiêu bài học
Nắm cách khai báo biến, kiểu nguyên thủy và kiểu tham chiếu trong Java.

## Khái niệm
Java kiểm tra kiểu tĩnh nên kiểu của biến được xác định khi biên dịch.

## Ví dụ code Java
```java
int age = 20;
double score = 9.5;
String name = "Mai";
final int MAX_RETRY = 3;
```

## Bài tập thực hành
Khai báo biến lưu tên, tuổi và điểm trung bình rồi in chúng ra màn hình.
