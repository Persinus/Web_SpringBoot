# Array

## Mục tiêu bài học
Khai báo, truy cập và duyệt mảng trong Java.

## Khái niệm
Array lưu nhiều phần tử cùng kiểu với kích thước cố định. Index bắt đầu từ 0.

## Ví dụ code Java
```java
int[] scores = {8, 9, 10};
System.out.println(scores[0]);
```

## Bài tập thực hành
Tìm phần tử lớn nhất trong một mảng số nguyên.
