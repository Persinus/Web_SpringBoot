# ArrayList

## Mục tiêu bài học
Làm việc với danh sách có kích thước linh hoạt bằng ArrayList.

## Khái niệm
ArrayList dùng mảng bên trong và tự mở rộng khi cần. Truy cập theo index nhanh.

## Ví dụ code Java
```java
List<String> names = new ArrayList<>();
names.add("An");
names.add("Binh");
```

## Bài tập thực hành
Thêm, xóa và tìm phần tử trong ArrayList.
