# Exception

## Mục tiêu bài học
Nhận diện và xử lý tình huống bất thường khi chương trình chạy.

## Khái niệm
Exception biểu diễn lỗi hoặc điều kiện bất thường cần được xử lý hoặc truyền lên.

## Ví dụ code Java
```java
throw new IllegalArgumentException("Invalid value");
```

## Bài tập thực hành
Kiểm tra input và ném exception có message rõ ràng.
