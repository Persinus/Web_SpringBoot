# HashMap và TreeMap

## Mục tiêu bài học
Lưu dữ liệu theo cặp key-value.

## Khái niệm
HashMap tối ưu tra cứu theo key, TreeMap duy trì key theo thứ tự.

## Ví dụ code Java
```java
Map<String, Integer> scores = new HashMap<>();
scores.put("An", 9);
```

## Bài tập thực hành
Đếm tần suất xuất hiện của các từ.
