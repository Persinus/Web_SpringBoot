# if / else

## Mục tiêu bài học
Điều khiển luồng chương trình theo điều kiện.

## Khái niệm
`if` chạy một nhánh khi điều kiện đúng, còn `else` xử lý trường hợp ngược lại.

## Ví dụ code Java
```java
if (score >= 5) {
  System.out.println("Pass");
} else {
  System.out.println("Try again");
}
```

## Bài tập thực hành
Phân loại một số là dương, âm hoặc bằng không.
