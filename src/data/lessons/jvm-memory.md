# JVM Memory

## Mục tiêu bài học
Hiểu stack, heap và vòng đời object trong JVM.

## Khái niệm
Stack chứa frame của thread, heap chứa object; thiết kế allocation ảnh hưởng hiệu năng.

## Ví dụ code Java
```java
User user = new User("An");
```

## Bài tập thực hành
Quan sát allocation bằng profiler.
