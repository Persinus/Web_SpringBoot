# Toán tử

## Mục tiêu bài học
Sử dụng toán tử số học, so sánh và logic trong biểu thức Java.

## Khái niệm
Toán tử kết hợp các giá trị để tạo ra kết quả mới. Cần chú ý thứ tự ưu tiên và short-circuit của toán tử logic.

## Ví dụ code Java
```java
int total = 7 + 3 * 2;
boolean valid = total > 10 && total < 20;
```

## Bài tập thực hành
Viết biểu thức kiểm tra một số có nằm trong khoảng từ 1 đến 100 hay không.
