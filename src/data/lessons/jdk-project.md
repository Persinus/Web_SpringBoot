# Cài đặt JDK và cấu trúc Java Project

## Mục tiêu bài học
Biết cài JDK và nhận diện các thư mục cơ bản của một Java Project.

## Khái niệm
JDK cung cấp compiler, công cụ chạy và thư viện cần thiết để phát triển Java. Một project thường có thư mục `src` chứa mã nguồn và thư mục build chứa file biên dịch.

## Cú pháp
```java
public class Main {
  public static void main(String[] args) {
    System.out.println("Project ready");
  }
}
```

## Bài tập thực hành
Tạo một project mới, đặt tên rõ nghĩa và chạy class Main thành công.
