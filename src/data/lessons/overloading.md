# Method Overloading

## Mục tiêu bài học
Định nghĩa nhiều method cùng tên với signature khác nhau.

## Khái niệm
Overloading được quyết định lúc compile-time dựa vào danh sách tham số.

## Ví dụ code Java
```java
int sum(int a, int b) { return a + b; }
double sum(double a, double b) { return a + b; }
```

## Bài tập thực hành
Overload method format cho nhiều kiểu dữ liệu.
