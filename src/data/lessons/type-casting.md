# Type Casting

## Mục tiêu bài học
Biết chuyển đổi giữa các kiểu dữ liệu nguyên thủy một cách an toàn.

## Khái niệm
Widening conversion thường tự động, còn narrowing conversion cần ép kiểu rõ ràng và có thể mất dữ liệu.

## Ví dụ code Java
```java
double price = 19.5;
int rounded = (int) price;
System.out.println(rounded);
```

## Bài tập thực hành
Thử chuyển đổi một số thực sang số nguyên và quan sát phần thập phân.
