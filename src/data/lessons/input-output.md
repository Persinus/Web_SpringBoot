# Input / Output

## Mục tiêu bài học
Đọc dữ liệu từ bàn phím và in kết quả ra console.

## Khái niệm
`System.out` dùng để xuất dữ liệu. `Scanner` giúp đọc dữ liệu cơ bản từ bàn phím.

## Ví dụ code Java
```java
Scanner scanner = new Scanner(System.in);
String name = scanner.nextLine();
System.out.println("Hello " + name);
```

## Bài tập thực hành
Nhập tên và tuổi người dùng rồi in một câu giới thiệu.
