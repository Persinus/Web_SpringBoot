# Annotation

## Mục tiêu bài học
Gắn metadata cho code và hiểu cách framework đọc metadata.

## Khái niệm
Annotation có retention policy và target khác nhau.

## Ví dụ code Java
```java
@Override
public String toString() { return "User"; }
```

## Bài tập thực hành
Tạo annotation đánh dấu class cần kiểm tra.
