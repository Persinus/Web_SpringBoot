# Method Reference

## Mục tiêu bài học
Viết lambda ngắn gọn bằng cách tham chiếu method đã có.

## Khái niệm
Method reference dùng `::` và làm rõ ý định khi method phù hợp.

## Ví dụ code Java
```java
names.forEach(System.out::println);
```

## Bài tập thực hành
Chuyển các lambda đơn giản thành method reference.
