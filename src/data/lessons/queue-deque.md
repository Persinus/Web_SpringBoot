# Queue và Deque

## Mục tiêu bài học
Xử lý dữ liệu theo thứ tự vào trước ra trước hoặc hai đầu.

## Khái niệm
Queue thường dùng FIFO, Deque hỗ trợ thêm/xóa ở cả đầu và cuối.

## Ví dụ code Java
```java
Deque<String> tasks = new ArrayDeque<>();
tasks.addLast("build");
```

## Bài tập thực hành
Tạo hàng đợi tác vụ với ưu tiên ở hai đầu.
