# Reflection

## Mục tiêu bài học
Đọc metadata và gọi thành phần runtime khi thật sự cần.

## Khái niệm
Reflection linh hoạt nhưng giảm type safety và có chi phí bảo trì.

## Ví dụ code Java
```java
Class<?> type = Class.forName("java.lang.String");
```

## Bài tập thực hành
Đọc tên method bằng reflection.
