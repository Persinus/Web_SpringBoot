# String

## Mục tiêu bài học
Làm việc với chuỗi và các method thường dùng của String.

## Khái niệm
String là immutable. Các thao tác biến đổi chuỗi thường trả về một String mới.

## Ví dụ code Java
```java
String message = "Java";
System.out.println(message.toUpperCase());
```

## Bài tập thực hành
Đếm số ký tự và kiểm tra một chuỗi có chứa từ khóa hay không.
